# `frontend-beta/tests` Folder Guide

This folder contains frontend verification suites.

## Contents

| Path | Purpose |
| --- | --- |
| `contract/` | Contract checks for backend payload compatibility. |
| `e2e/` | End-to-end browser flow tests. |

## How This Folder Fits Into DeepMail

- Contract tests protect the frontend from backend shape drift.
- E2E tests validate visible user flows such as map interaction.
