# `frontend-beta/src/components` Folder Guide

This folder contains reusable presentation and feature components.

## Contents

| Path | Purpose |
| --- | --- |
| `blocks/` | Section-sized presentational blocks. |
| `dashboard/` | Dashboard-specific visualizations. |
| `graph/` | Graph-specific side panels and UI. |
| `layout/` | Shared app shell components. |
| `map/` | Map-specific rendering and interaction components. |
| `ui/` | Low-level reusable UI building blocks. |
| `Landing*.tsx` | Landing-page feature sections and marketing components. |

## Key Files And Functions

- `LandingHero.tsx`: hero section for the landing page.
- `LandingNavbar.tsx`: top navigation shell for the landing page.
- `LandingFeatures.tsx`: product capability/feature presentation.
- `LandingHowItWorks.tsx`: step-based explanation of the analysis flow.
- `LandingPricing.tsx`: pricing/pass-through presentation.
- `LandingStats.tsx`: landing page metrics section.
- `LandingCTAFooter.tsx`: closing call-to-action section.
- `LandingModals.tsx`: landing-page modal UI.
