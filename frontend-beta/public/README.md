# `frontend-beta/public` Folder Guide

This folder contains static assets served directly by Next.js.

## Files

| File | Purpose |
| --- | --- |
| `file.svg` | Static SVG asset bundled with the prototype. |
| `globe.svg` | Static SVG asset bundled with the prototype. |
| `next.svg` | Static Next.js-related SVG asset. |
| `vercel.svg` | Static Vercel-related SVG asset. |
| `window.svg` | Static SVG asset bundled with the prototype. |

## Editing Guidance

- Keep only reusable static assets here.
- Avoid placing generated screenshots or temporary exports in this folder.
