# `frontend-beta/src/components/layout` Folder Guide

This folder contains shared layout-shell components.

## Files

| File | Purpose |
| --- | --- |
| `TopBar.tsx` | Top navigation/status strip for application screens. |
| `Sidebar.tsx` | Side navigation and screen selection UI. |
| `StatusFooter.tsx` | Footer/status summary component. |

## Key Files And Functions

- `TopBar`: renders top-of-screen application status and navigation controls.
- `Sidebar`: renders the primary side navigation shell.
- `StatusFooter`: renders footer-level status and summary information.
