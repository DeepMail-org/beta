Database Schema

Complete per-service PostgreSQL schema for all 24 backend services. Every table, column, data type, constraint, index, and foreign key — designed from scratch for production.

24 Services PostgreSQL 16 Neo4j (Graph) SQLx query! macro Per-service isolation No shared DB access UUID v4 primary keys TIMESTAMPTZ everywhere

Pricing Philosophy — Cost-Pass-Through Model

No profit margin on infrastructure. Users are charged exactly what the underlying APIs and compute cost. AbuseIPDB free tier ($0), VirusTotal ~$0.01-0.05/lookup, IPInfo $0.0001/request after 50k free/month, GreyNoise community free, Shodan $0.001/lookup, Firecracker VM ~$0.002/minute compute, S3/MinIO ~$0.023/GB storage. The cost_config table in deepmail_billing stores real-time unit costs synced from each provider and is the single source of truth for what gets charged.

-- ─────────────────────────────────────────────────────────────
--  deepmail_auth  ·  Authentication & Identity
--  DB: deepmail_auth  (isolated PostgreSQL schema)
--  Engine: PostgreSQL 16 + pgcrypto + uuid-ossp
-- ─────────────────────────────────────────────────────────────

CREATE EXTENSION IF NOT EXISTS "pgcrypto";
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";
CREATE EXTENSION IF NOT EXISTS "citext";       -- case-insensitive text for email

-- ── USERS ────────────────────────────────────────────────────
CREATE TABLE users (
  id               UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
  username         TEXT        NOT NULL UNIQUE,
  email            CITEXT      NOT NULL UNIQUE,        -- case-insensitive
  password_hash    TEXT        NOT NULL,               -- argon2id hash
  is_active        BOOLEAN     NOT NULL DEFAULT false, -- true after email verified
  email_verified   BOOLEAN     NOT NULL DEFAULT false,
  is_flagged       BOOLEAN     NOT NULL DEFAULT false, -- admin can flag abusers
  flagged_reason   TEXT,
  created_at       TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at       TIMESTAMPTZ NOT NULL DEFAULT now(),
  last_login_at    TIMESTAMPTZ,
  deleted_at       TIMESTAMPTZ                         -- soft delete
);

-- ── OTP CODES ─────────────────────────────────────────────────
-- Never store plaintext OTP. Store argon2id hash of the code.
-- One active OTP per user per type at a time.
CREATE TABLE otp_codes (
  id             UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id        UUID        NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  code_hash      TEXT        NOT NULL,     -- argon2id($code)
  otp_type       TEXT        NOT NULL
    CHECK (otp_type IN ('login', 'registration', 'password_reset', 'email_change')),
  expires_at     TIMESTAMPTZ NOT NULL,     -- 10 minutes from creation
  attempts       INTEGER     NOT NULL DEFAULT 0,
  max_attempts   INTEGER     NOT NULL DEFAULT 5,
  used           BOOLEAN     NOT NULL DEFAULT false,
  used_at        TIMESTAMPTZ,
  ip_address     INET,
  user_agent     TEXT,
  created_at     TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- ── REFRESH TOKENS ────────────────────────────────────────────
CREATE TABLE refresh_tokens (
  id             UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id        UUID        NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  token_hash     TEXT        NOT NULL UNIQUE, -- SHA-256 of actual token
  device_info    TEXT,
  ip_address     INET,
  expires_at     TIMESTAMPTZ NOT NULL,       -- 7 days
  revoked        BOOLEAN     NOT NULL DEFAULT false,
  revoked_at     TIMESTAMPTZ,
  revoke_reason  TEXT,                         -- 'logout','rotation','admin'
  created_at     TIMESTAMPTZ NOT NULL DEFAULT now(),
  last_used_at   TIMESTAMPTZ
);

-- ── API KEYS ──────────────────────────────────────────────────
-- Key format: dm_live_{random_32_chars}
-- prefix stored, full key hashed, prefix shown to user in UI
CREATE TABLE api_keys (
  id           UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id      UUID        NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  tenant_id    UUID        NOT NULL,      -- FK to tenant service (cross-service)
  name         TEXT        NOT NULL,      -- user-defined label
  key_prefix   TEXT        NOT NULL,      -- first 12 chars: dm_live_xxxx
  key_hash     TEXT        NOT NULL UNIQUE, -- SHA-256 of full key
  scopes       TEXT[]      NOT NULL DEFAULT '{}',
    -- ['read:analysis','write:upload','read:report','admin:all']
  last_used_at TIMESTAMPTZ,
  expires_at   TIMESTAMPTZ,               -- NULL = never expires
  revoked      BOOLEAN     NOT NULL DEFAULT false,
  revoked_at   TIMESTAMPTZ,
  created_at   TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- ── LOGIN ATTEMPTS ────────────────────────────────────────────
-- Track every auth attempt regardless of outcome for brute force detection.
CREATE TABLE login_attempts (
  id              UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
  email           CITEXT,     -- may not be a real user (enumeration)
  user_id         UUID        REFERENCES users(id) ON DELETE SET NULL,
  ip_address      INET        NOT NULL,
  user_agent      TEXT,
  success         BOOLEAN     NOT NULL,
  failure_reason  TEXT,
    -- 'invalid_password','invalid_otp','account_locked',
  --    'otp_expired','max_attempts','account_inactive'
  otp_stage       BOOLEAN     NOT NULL DEFAULT false, -- failed at OTP step?
  created_at      TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- ── IP LOCKOUTS ───────────────────────────────────────────────
-- 5 failed attempts = 15 minute lockout. Exponential backoff on repeat.
CREATE TABLE ip_lockouts (
  id             UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
  ip_address     INET        NOT NULL UNIQUE,
  locked_until   TIMESTAMPTZ NOT NULL,
  attempt_count  INTEGER     NOT NULL DEFAULT 0,
  lockout_count  INTEGER     NOT NULL DEFAULT 0, -- how many times locked
  created_at     TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at     TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- ── AUDIT LOGS ────────────────────────────────────────────────
CREATE TABLE audit_logs (
  id             UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id        UUID        REFERENCES users(id) ON DELETE SET NULL,
  action         TEXT        NOT NULL,
    -- 'login_success','login_fail','logout','otp_sent','otp_verified',
  --    'password_changed','api_key_created','api_key_revoked','account_deleted'
  resource_type  TEXT,
  resource_id    UUID,
  ip_address     INET,
  user_agent     TEXT,
  metadata       JSONB       NOT NULL DEFAULT '{}',
  created_at     TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- ── INDEXES ───────────────────────────────────────────────────
CREATE INDEX idx_users_email          ON users(email)       WHERE deleted_at IS NULL;
CREATE INDEX idx_users_username       ON users(username)   WHERE deleted_at IS NULL;
CREATE INDEX idx_otp_user_type        ON otp_codes(user_id, otp_type) WHERE used = false;
CREATE INDEX idx_otp_expires          ON otp_codes(expires_at)         WHERE used = false;
CREATE INDEX idx_refresh_user         ON refresh_tokens(user_id)        WHERE revoked = false;
CREATE INDEX idx_refresh_expires      ON refresh_tokens(expires_at)     WHERE revoked = false;
CREATE INDEX idx_api_keys_user        ON api_keys(user_id)            WHERE revoked = false;
CREATE INDEX idx_api_keys_tenant      ON api_keys(tenant_id)          WHERE revoked = false;
CREATE INDEX idx_login_ip_time        ON login_attempts(ip_address, created_at);
CREATE INDEX idx_login_email_time     ON login_attempts(email, created_at);
CREATE INDEX idx_login_user_time      ON login_attempts(user_id, created_at);
CREATE INDEX idx_audit_user_time      ON audit_logs(user_id, created_at);
CREATE INDEX idx_audit_action         ON audit_logs(action, created_at);

Ingestion
deepmail_ingest
Receives uploaded .eml/.msg files. Multi-layer validation: extension → size → magic bytes → MIME type → canonical path. UUID-renames and quarantines to S3 with 0o400 permissions. Computes SHA-256. Creates the central email record that all other services reference.
SHA-256 fingerprint Magic byte check Quarantine 0o400 S3/MinIO NATS publish

CREATE EXTENSION IF NOT EXISTS "pgcrypto";

-- ── EMAILS ────────────────────────────────────────────────────
-- Central email record. Created by ingest service.
-- All other services reference email_id (cross-service UUID reference).
CREATE TABLE emails (
  id                  UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id           UUID        NOT NULL,
  uploaded_by         UUID        NOT NULL,            -- ref auth.users.id
  original_filename   TEXT        NOT NULL,
  quarantine_name     TEXT        NOT NULL UNIQUE,     -- UUID-renamed on disk
  s3_bucket           TEXT        NOT NULL,
  s3_key              TEXT        NOT NULL,
  sha256_hash         TEXT        NOT NULL,
  md5_hash            TEXT        NOT NULL,
  file_size_bytes     BIGINT      NOT NULL,
  file_extension      TEXT        NOT NULL,            -- .eml or .msg
  mime_type           TEXT        NOT NULL,
  magic_bytes_valid   BOOLEAN     NOT NULL DEFAULT false,

-- ── JOB PROGRESS ──────────────────────────────────────────────

CREATE TABLE job_progress (

  nats_message_id  TEXT,
  retry_count      INTEGER     NOT NULL DEFAULT 0,
  error_message    TEXT,
  started_at       TIMESTAMPTZ,
  completed_at     TIMESTAMPTZ,
  duration_ms      INTEGER,
  created_at       TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE(email_id, stage)
);

-- ── INDEXES ───────────────────────────────────────────────────
CREATE INDEX idx_emails_tenant          ON emails(tenant_id, uploaded_at DESC) WHERE deleted_at IS NULL;

deepmail_parser
Full RFC 5322 email parsing. Builds complete MIME tree. Extracts every header as key-value pairs. Reconstructs the full Received-header chain with sequence numbers. Separates body (plain + HTML) and all attachments. Detects encoding (base64, quoted-printable, etc.).
RFC 5322 MIME tree Received chain Attachment extraction Encoding detection

  created_at          TIMESTAMPTZ NOT NULL DEFAULT now()

deepmail_header
Full email header forensics. SPF/DKIM/DMARC/Return-Path/Reply-To mismatch/Message-ID fake generator detection/X-Mailer fingerprinting/time anomaly detection across the full Received chain. Each check stored as an individual finding with severity and evidence.
SPF validation DMARC policy Reply-To mismatch Message-ID analysis Time anomaly X-Mailer fingerprint

CREATE EXTENSION IF NOT EXISTS "pgcrypto";

-- ── HEADER ANALYSES ───────────────────────────────────────────
-- Master record per email. All sub-checks reference this.
CREATE TABLE header_analyses (
  id                      UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
  email_id                UUID        NOT NULL UNIQUE,
  tenant_id               UUID        NOT NULL,
  overall_risk_score      REAL        NOT NULL DEFAULT 0.0,   -- 0.0-1.0
  spf_result              TEXT        -- pass,fail,softfail,neutral,none,permerror,temperror
    CHECK (spf_result IN ('pass','fail','softfail','neutral','none','permerror','temperror')),
  spf_domain              TEXT,
  spf_sender_ip           INET,
  dkim_result             TEXT
    CHECK (dkim_result IN ('pass','fail','none','policy','neutral','temperror','permerror')),
  dkim_domain             TEXT,
  dkim_selector           TEXT,
  dmarc_result            TEXT
    CHECK (dmarc_result IN ('pass','fail','none','temperror','permerror')),
  dmarc_policy            TEXT,                         -- none,quarantine,reject
  dmarc_domain            TEXT,
  return_path_domain      TEXT,
  return_path_mismatch    BOOLEAN     NOT NULL DEFAULT false,
  reply_to_mismatch       BOOLEAN     NOT NULL DEFAULT false,
  reply_to_domain         TEXT,
  from_domain             TEXT,
  message_id_valid        BOOLEAN,
  message_id_domain       TEXT,
  message_id_domain_match BOOLEAN,                      -- does msg-id domain = from domain?
  message_id_fake_pattern BOOLEAN     NOT NULL DEFAULT false, -- known fake MUA patterns
  x_mailer                TEXT,
  x_mailer_risk           TEXT        CHECK (x_mailer_risk IN ('none','low','medium','high')),
  x_mailer_known_kit      TEXT,                         -- matched malware kit name if known
  sender_spoofing_likely  BOOLEAN     NOT NULL DEFAULT false,
  analyzed_at             TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- ── TIME ANOMALY ANALYSIS ─────────────────────────────────────
-- Cross-correlates timestamps across all Received headers and Date header.
CREATE TABLE time_anomalies (

  earliest_received_ts TIMESTAMPTZ,
  latest_received_ts   TIMESTAMPTZ,
  future_dated         BOOLEAN     NOT NULL DEFAULT false, -- Date: > now()
  date_predates_recv   BOOLEAN     NOT NULL DEFAULT false, -- Date: < first Received:
  max_hop_delay_sec    INTEGER,                             -- largest gap between hops
  suspicious_delay     BOOLEAN     NOT NULL DEFAULT false, -- gap > 1 hour
  timezone_anomaly     BOOLEAN     NOT NULL DEFAULT false, -- unusual tz offset
  total_transit_sec    INTEGER,
  hop_count            INTEGER,
  created_at           TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- ── DNS LOOKUP RESULTS ────────────────────────────────────────
-- SPF/DMARC TXT record values + TTL for evidence trail.

// ─────────────────────────────────────────────────────────────
//  DeepMail · Neo4j Graph Schema
//  All nodes have: id (UUID), created_at, updated_at
// ─────────────────────────────────────────────────────────────

// ── NODE CONSTRAINTS ─────────────────────────────────────────
CREATE CONSTRAINT email_id    IF NOT EXISTS FOR (n:Email)    REQUIRE n.id    IS UNIQUE;
CREATE CONSTRAINT ip_address  IF NOT EXISTS FOR (n:IP)       REQUIRE n.value IS UNIQUE;
CREATE CONSTRAINT domain_val  IF NOT EXISTS FOR (n:Domain)   REQUIRE n.value IS UNIQUE;
CREATE CONSTRAINT url_val     IF NOT EXISTS FOR (n:URL)      REQUIRE n.normalized IS UNIQUE;
CREATE CONSTRAINT hash_sha256 IF NOT EXISTS FOR (n:Hash)     REQUIRE n.sha256 IS UNIQUE;
CREATE CONSTRAINT actor_id    IF NOT EXISTS FOR (n:Actor)    REQUIRE n.id    IS UNIQUE;
CREATE CONSTRAINT c2_id       IF NOT EXISTS FOR (n:C2Server) REQUIRE n.id    IS UNIQUE;
CREATE CONSTRAINT campaign_id IF NOT EXISTS FOR (n:Campaign) REQUIRE n.id    IS UNIQUE;
CREATE CONSTRAINT asn_num     IF NOT EXISTS FOR (n:ASN)      REQUIRE n.number IS UNIQUE;

// ── NODE PROPERTY SCHEMAS ────────────────────────────────────

// :Email { id, tenant_id, sha256, subject, from_address,
//          threat_score, severity, uploaded_at, has_attachments }
//
// :IP { value, country_code, asn_number, is_tor, is_vpn,
//       is_hosting, is_botnet, abuse_score, lat, lon,
//       city, org, first_seen, last_seen }
//
// :Domain { value, registrar, registered_at, country_code,
//           is_idn, is_homograph, brand_similarity_score,
//           first_seen, last_seen }
//
// :URL { raw, normalized, final_url, domain, is_shortener,
//        is_c2_beacon, screenshot_s3_key, risk_score }
//
// :Hash { sha256, md5, ssdeep, imphash, file_type,
//         verdict, malware_family, first_seen, seen_count }
//
// :Actor { id, name, aliases, country, motivation,
//          first_seen, last_seen, confidence }
//
// :C2Server { id, ip, domain, protocol, port,
//             malware_family, confidence, active }
//
// :Campaign { id, name, confidence, ioc_count,
//             email_count, mitre_ttps, first_seen, last_seen }
//
// :ASN { number, org, country, is_hosting, is_bulletproof }
// ─────────────────────────────────────────────────────────────

// ── RELATIONSHIP TYPES ───────────────────────────────────────
// (:Email)-[:SENT_VIA {hop_index, timestamp}]->(:IP)
// (:Email)-[:CONTAINS_URL]->(:URL)
// (:Email)-[:CONTAINS_HASH]->(:Hash)
// (:Email)-[:FROM_DOMAIN]->(:Domain)
// (:Email)-[:MEMBER_OF {similarity, confidence}]->(:Campaign)
// (:IP)-[:RESOLVES_TO {ttl, queried_at}]->(:Domain)
// (:IP)-[:BELONGS_TO]->(:ASN)
// (:IP)-[:IS_C2]->(:C2Server)
// (:Domain)-[:HOSTED_ON]->(:IP)
// (:Domain)-[:REDIRECTS_TO]->(:URL)
// (:URL)-[:DOWNLOADS]->(:Hash)

Global Design Rules Applied Across All Schemas
✓ All PKs are UUID DEFAULT gen_random_uuid() — no sequential int IDs
✓ All timestamps use TIMESTAMPTZ — never TIMESTAMP without timezone
✓ All email fields use CITEXT — case-insensitive, no lowercasing bugs
✓ All IP address fields use INET type — supports IPv4 and IPv6, enables GIST indexing
✓ CIDR ranges use CIDR type with GIST (inet_ops) for range containment queries
✓ All monetary values stored as INTEGER (paise) — no FLOAT for money, ever
✓ Soft deletes via deleted_at TIMESTAMPTZ + partial index WHERE deleted_at IS NULL
✓ All array fields use TEXT[] / INTEGER[] — never comma-separated strings
✓ All flexible payloads use JSONB — not JSON, JSONB for indexability
✓ All CHECK constraints validate enum-like text fields at the DB level
✓ All scores/confidence stored as REAL (0.0–1.0) — normalized range enforced
✓ Cross-service references are bare UUID fields (no FK) — services are isolated
✓ Idempotency keys are UUID UNIQUE NOT NULL — prevents double-processing on retry
✓ All migrations are idempotent — CREATE TABLE IF NOT EXISTS, CREATE INDEX IF NOT EXISTS
✓ Partial indexes on status columns — WHERE status = 'pending' keeps index tiny and fast
✓ All tables include created_at TIMESTAMPTZ NOT NULL DEFAULT now()
