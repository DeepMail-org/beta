# `frontend-beta/src/components/ui` Folder Guide

This folder contains lower-level reusable UI primitives and decorative visual components.

## Files

| File | Purpose |
| --- | --- |
| `button.tsx` | Base button component. |
| `button-witn-icon.tsx` | Button variant with icon support. |
| `card.tsx` | Shared card container component. |
| `file-upload.tsx` | File-upload interaction component. |
| `hover-brand-logo.tsx` | Interactive brand/logo presentation element. |
| `liquid-glass-button.tsx` | Stylized call-to-action button component. |
| `motion-footer.tsx` | Animated footer component. |
| `multi-step-loader.tsx` | Multi-stage loading/progress display. |
| `orbiting-circles.tsx` | Decorative orbit animation component. |
| `radar-effect.tsx` | Radar-style animated visual effect. |
| `remocn-perspective-marquee.tsx` | Perspective marquee effect component. |

## Key Files And Functions

- Each file exports one reusable UI component used by the landing page or application views.
- `file-upload.tsx` is the most domain-oriented component in this folder and supports the upload route UX.

## Editing Guidance

- Keep this folder focused on reusable UI pieces rather than route-specific business logic.
